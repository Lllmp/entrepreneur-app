# 💼 Mr. Stumberg's Financial Literacy Adventure

This Streamlit app helps 1st grade students brainstorm a business idea, choose a name and slogan, and generate a flyer advertisement using OpenAI.

## 🚀 Features

- Student-friendly business idea generation
- Creativity slider for naming
- AI-generated slogans
- Flyer design via OpenAI’s GPT Image 1 (low-cost image generation)
